# Contributing

Three ways to help, smallest first.

1. **Disagree with a label.** Open an issue with the case `id`, the label you expect, and why. Labels are synthetic until a person reviews them.
2. **Report a slice that breaks an engine.** A request body, the engine and version, what it returned, what it should have returned.
3. **Submit a decision.** Use the "Submit a decision" issue template. Sanitized or look-alike cases are fine. Nothing private goes in a public issue.

Never commit API keys, customer data, or partner cases. Partner work lives outside this repo until the partner approves an anonymized version.
